# 确任任务方向收口

## 不要做成 58 同城式任务池

如果任务列表长期给人的感受是：

- 找人发传单
- 找人做活动兼职
- 找人临时搬砖

那用户自然会问：

> 我为什么不直接去 58 同城、闲鱼、本地兼职群？

这类需求的问题不是没有市场，而是：

- 平台同质化太强
- 用户对价格极度敏感
- 很难形成品牌记忆
- “保障”这件事在早期又还没建立起来

确任前期更应该做的，不是“更全的兼职市场”，而是：

## 更像城市协作与故事任务

更适合确任的任务类型：

- 陪我去看一个展，然后顺手帮我拍几张自然照片
- 陪我把一场普通生日过得稍微像电影一点
- 帮我替一段关系做一次体面的告别
- 帮我记录一个小活动里人与人之间真的在发生的感觉
- 陪家里长辈去一次办事窗口或医院，负责耐心解释和流程陪同
- 帮我去城市里收集某种主题的画面、声音或情绪
- 帮我把租来的房间改得更像“我在这里生活”
- 陪我做一次我一直想做但总一个人不敢开始的小计划

这类任务和传统兼职的差异在于：

- 不是标准劳务
- 更强调陪伴、表达、体验、审美、信任
- 更容易沉淀故事内容
- 更适合短视频和内容传播
- 更容易形成“这就是确任”的独特心智

## 产品上应优先强化的方向

### 1. 任务要有故事感

任务卡不只是：

- 标题
- 预算
- 地点

还要强调：

- 为什么做这件事
- 期待什么感觉
- 对方最好是什么样的人

### 2. 平台要更像“找到合适的人”

不是“谁便宜谁上”，而是：

- 谁更适合这类任务
- 谁更会沟通
- 谁更有审美/陪伴/表达能力

所以信用、评价、气质、过往故事，比单纯价格更重要。

### 3. 首页要保持克制

首页核心继续保留：

- 搜索
- 热力图
- 任务广场
- 任务故事墙

但任务内容本身要越来越像：

- 城市协作
- 情绪陪伴
- 创意执行
- 生活体验

而不是“临时兼职公告栏”。

## 内容运营方向

前期最容易被传播的，不是“接单赚钱”，而是：

- 最温柔的一条任务
- 最离谱但真实的一条任务
- 最有城市气息的一条任务
- 最像电影片段的一次协作

所以 seed、首页故事墙、运营精选，都应该往这个方向倾斜。

## 当前执行结论

接下来确任的演示数据、故事墙和推荐任务，优先使用：

- 有情绪
- 有场景
- 有人味
- 有内容传播潜力

的任务，而尽量减少“标准兼职感”的内容占比。
